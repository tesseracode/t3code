# Acceptance

- Both native create and resume explicitly decline standalone extensions.
- An extension-requesting fixture can start, accept a harmless prompt and settle
  under the configured host capability.
- Skills, project discovery and T3 MCP support remain independently configured.
- Cold resume retains the original native ID; no replacement or prompt replay.
- Preserve visible failures for unrelated startup errors.
- Track https://github.com/tesseracode/t3code/issues/38.
- Do not claim an unconditional No project bug or platform matrix not executed.
