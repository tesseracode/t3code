# Shared surfaces

Provider settings annotations generate web/mobile configuration controls.
resolveClientConfiguration supplies both discovery and conversation subprocesses.
modelsFromSdk supplies names and capabilities to all clients. Shared model
descriptor normalization supplies trait dropdowns and keybinding cycles.
adapter textEvent is the common live/replay answer boundary; Fusion phase and
final-source metadata already flow through shared model-execution activity items.

Native send acknowledges the user message ID; root assistant snapshots expose its
originatingMessageId. Adapter ownership maps can join those exact IDs rather than
infer association from Fusion's unrelated turn-ID namespace. ProviderEventIngestor
already preserves persisted ownership on cold reimport. TurnItemPositionStore must
promote an unbound position once that ownership is confirmed.
