# Analysis

Account-bound global/session SDK catalogs currently omit Fusion-tier metadata
with both runtimes and both experimental settings. Do not invent tier IDs or
claim real High/Max execution. Attribution and event-order behavior can be
improved independently with provider-reported events and focused regressions.

Auto Intent resolution is currently dropped. Preserve its chosen model as
selection evidence, not execution proof or an inferred Fusion plan. Its event
has no semantic turn ID, so keep it visibly unassociated rather than assigning it
to whichever run happens to be active.

A late Fusion resolved event currently retains completion but loses newly
observed route metadata and leaves a stale missing-plan gap. A delayed phase
start retains terminal status but fails to enrich pattern/role/scope. Shared chat
summaries also omit the runtime-selected execution pattern.

One correction leaf hard-depending on the prior Auto fix preserves historical
SDK/Fusion evidence. Shared presentation covers web, desktop and mobile; no
contracts or other providers change. Real-tier picker rollout remains gated.
