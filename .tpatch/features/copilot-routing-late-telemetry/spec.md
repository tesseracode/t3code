# Routing attribution and reordered events

- Persist bounded Auto Intent chosen-model metadata without copying classifier
  payloads, prompts or inventing Fusion/execution/turn attribution.
- Late Fusion route plans enrich metadata and clear only obsolete missing-plan
  gaps without overwriting authoritative completion status, source or time.
- Delayed phase starts enrich pattern, role and conversation scope while
  retaining terminal outcomes and observed-versus-estimated timing.
- Shared activity summaries expose resolved virtual model and execution pattern;
  actual final models remain distinct from selected models and planned fallback.
- Cover route-before-turn-start, phase-before-route and completion-before-plan.
  Metadata updates never create additional user turns or finish the root.
- Show actual live default-Auto results where possible; label fixture-only
  evidence separately. Live explicit Fusion tiers remain blocked when absent.
