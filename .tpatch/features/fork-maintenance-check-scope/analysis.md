# Analysis

The required v0.1.4 changed checker includes inherited `.tpatch` history as
application input. It reports formatting failures for hash-bound generation
manifests and historical records, lints an archived recipe generator with current
application comment rules, and classifies every administrative path as an
unknown change requiring all package jobs.

Formatting those archives would alter retained evidence without changing the
product. Treat the literal `.tpatch/` namespace like existing administrative
directories in package-impact classification and preserve its bytes through
formatter/linter exclusions. Product files materialized by patches remain fully
checked, and independent replay/feature integrity remain separate requirements.

This is contributor tooling only. It does not waive any runtime, type, test,
unused-code, native-platform or release gate.
